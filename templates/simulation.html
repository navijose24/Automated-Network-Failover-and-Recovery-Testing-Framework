Why Real Linux Kernel Namespaces?

Unlike simulations that simply toggle HTML variables, this framework operates directly on the Linux network stack using isolated network namespaces (ip netns). Each namespace maintains its own independent routing tables, firewall rules, and virtual Ethernet network devices.

Threshold-Based Failure Detection

In enterprise production networks, a single lost ICMP probe or momentary jitter must not trigger a full route reconvergence. The framework enforces a configurable consecutive failure threshold (default: 3 missed probes) before raising FAILURE_DETECTED and promoting the backup route.
